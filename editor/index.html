Eco Era site editor

Edit the website's words and photos, then publish your changes to GitHub.

First time here? Connect the editor to GitHub with an access key. You only do this once on each computer.

  1. Open GitHub → New access token (sign in as the Posada Natura account).
  2. Name it Eco Era editor. Under Expiration, choose the longest option you're comfortable with.
  3. Under Repository access, choose Only select repositories, then pick ecoera.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.

The key is saved only in this browser, on this computer. Anyone with it can change the website, so don't share it.
